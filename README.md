# Java Conta Bancária

Projeto desenvolvido em Java durante meus estudos de Programação Orientada a Objetos.

## 📚 Sobre o projeto

O projeto simula uma conta bancária e foi desenvolvido com o objetivo de praticar conceitos fundamentais da Programação Orientada a Objetos em Java.

Durante o desenvolvimento, foram trabalhados conceitos como:

- Classes e objetos
- Encapsulamento
- Construtores
- Sobrecarga de métodos
- Uso do `this`
- Métodos e atributos

## 🛠️ Tecnologias

- Java

## 🎯 Objetivo

Consolidar os fundamentos de Programação Orientada a Objetos e desenvolver maior familiaridade com a linguagem Java por meio de um projeto prático.

## 📖 Contexto

Este projeto faz parte da minha jornada de estudos em Java e representa uma das etapas da construção da minha base para desenvolvimento Back-End.

## 🚀 Próximos passos

Continuar aprofundando meus conhecimentos em Java e posteriormente aplicar esses fundamentos no desenvolvimento de aplicações Back-End com Spring Boot e APIs REST.
